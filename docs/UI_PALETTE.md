# VBase — цветовая палитра (TD × Orcs Must Die)

Целевая визуальная тема: **тёплое тёмное фэнтези** (камень, дерево, железо) +
яркие смысловые акценты. Не sci-fi / не холодный электрик-синий.

Использовать при рисовании UI (`assets/ui/`), материалов мира, VFX и правок
`UiSkin` / `gen_ui_skin.py`. Техника 9-slice — в [UI_SKIN.md](UI_SKIN.md).

---

## 1. Общее направление

| Роль | Ощущение | Пример |
|------|----------|--------|
| Фон мира / UI | Тёмный, тёплый, «подземелье» | угольно-коричневый, не чистый `#000` |
| Поверхности | Камень / дерево / металл | серо-бурый, орех, железо |
| Акцент действия | Магия / опасность / награда | янтарь, изумруд, пурпур, кровь |
| Текст | Светлый тёплый | кремовый / тёплый белый |

Правило экрана: **один главный акцент** (обычно янтарь CTA). Остальные — точечно.

Формула: **тёплый тёмный камень + янтарь CTA + зелёный ресурс + красный threat + фиолетовый magic**.

## 6. Меню и кнопки (правила)

- Панель: `#2A221C` + рамка `#7A6A58` / медный rim `#C4A574`.
- Title bar: `#332820` + линия `#E8A13A` (~20–40% opacity) или `#C4A574`.
- Primary: заливка янтарь; hover светлее, press темнее.
- Secondary: тёмная заливка + обводка `#7A6A58`, текст `#F2E6D4`.
- Destructive: `#C43C32`, не янтарь.
- На таче кнопки «мясистые», не тонкий неон.

Ассеты: `panel.png`, `button_normal/hover/active.png` — генерируются
`python app/src/main/assets/ui/gen_ui_skin.py` в этой палитре.

## 7. Игровой мир

| Элемент | Цвет / материал |
|---------|-----------------|
| Пол / земля | Тёплый серо-коричневый (не холодный checker) |
| Стены / база | Stone `#4A3F35` + мох/грязь |
| Путь врагов | Чуть светлее/пыльнее пола |
| Свои здания | Тёплый камень + медные/янтарные руны |
| Враги | Оливковый / грязно-зелёный / бурый (кластер отдельно от UI) |
| Ядро (threat) | Пульс `#C43C32` → `#FF6A2A` |
| Ресурс | Зелёный / золото — **один** цвет в мире и HUD |

Освещение: тёплый key (торчи / закат), холодный fill слабый.

---

## 8. Чтобы «зашло» и не уставали глаза

1. Тёмный UI с тёплым undertone — не чистый чёрный.
2. Акценты насыщенные, фоны средние.
3. Контраст текста к панели: крем `#F2E6D4` на `#2A221C`.
4. Не радуга на всех кнопках — 1 CTA + 2 смысловых.
5. Мир и меню из одной семьи материалов.

## 11. Loading screen (арт + превью)

Концепт арта: **ядро базы** — пульсирующее тёплое «сердце»-артефакт в каменной нише,
медные руны, пыль в луче света. Full-bleed, без UI/текста на картинке.
Файл: `app/src/main/assets/ui/loading_core.png` (16:9).

**Превью в игре (ещё не настоящий лоадинг):**
- Кнопка в панели VBase → **Debug → «Показать лоадинг»**
- Десктоп: флаг `--loading` при старте (`vbase_desktop.exe --loading`)
- `GameUiState.showLoadingPreview` — рисует арт + пульс ядра/луча/пыли + фейковый бар
- Скрыть: кнопка «Скрыть» на оверлее

Настоящую загрузку ассетов/прогресс подключим позже; сейчас только визуал.
