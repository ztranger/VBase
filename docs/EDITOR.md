# Редактор сцен VBase

Десктопное приложение (`editor/`, Windows/OpenGL) для сборки и оформления уровней: расставить
объекты-декор, здания базы, спавнеры врагов, точки спавна, физ-колайдеры, настроить свет и камеру —
и сохранить всё в человекочитаемый `.scene`, который потом грузят клиент и сервер. Ядро движка
(рендер, загрузка сцен, glTF) переиспользуется из `app/src/main/cpp` (как `server/` и `desktop/`).

Редактор **офлайн**: без сети, симуляции и геймплея — только просмотр геометрии и правка данных сцены.

## Запуск

```bash
build-editor.cmd
```
Собирает `editor\build\vbase_editor.exe` (MSVC + Ninja, как сервер/десктоп).

```bash
run-editor.cmd [assetsDir] [scenePath]
```
Запуск из корня. По умолчанию `assetsDir = ../../app/src/main/assets`, `scenePath = scenes/default.scene`.
Примеры:
- `run-editor.cmd` — открыть сцену по умолчанию.
- `run-editor.cmd ../../app/src/main/assets scenes/maze.scene` — открыть конкретную сцену.

Рабочая папка — `editor/build`, поэтому относительные пути к ассетам разрешаются автоматически.

## Обзор экрана

- **Вьюпорт** (весь экран) — 3D-вид уровня с орбитальной камерой.
- **Панель «Редактор сцен»** (слева) — Save, режим гизмо, снап, инспектор выделенного, палитра
  добавления, свет, камера сцены, undo/redo, браузер `.glb`.
- **Окно «Outliner»** (справа) — список всех сущностей по категориям.
- **Колайдеры** видны тусклыми рамками (в игре невидимы — это физика), **точки спавна** — циановыми
  кубиками-маркерами (в игре невидимы). Выделенное подсвечено янтарной рамкой.

## Камера (облёт)

| Действие | Что делает |
|---|---|
| ЛКМ-драг (по пустому месту) | орбита вокруг точки фокуса |
| ПКМ / СКМ-драг | панорама (сдвиг фокуса) |
| Колесо | зум |
| Кнопка «Сбросить камеру» | вернуть камеру в исходное |

## Выделение

- **ЛКМ-клик** (без перетаскивания) по объекту/зданию/спавну/колайдеру — выбрать ближайший под
  курсором.
- **Клик по строке в Outliner** — выбрать эту сущность (двусторонний синк с 3D).
- **Двойной клик в Outliner** — навести камеру на сущность (фокус).
- Клик по пустому месту — снять выделение.

## Гизмо (перемещение / поворот / масштаб)

Появляется на выделенном. Режим переключается клавишами или радио в панели:

| Клавиша | Режим | Объекты | Здания / спавны / колайдеры |
|---|---|---|---|
| **W** | Перемещение | ✓ | ✓ (только перемещение) |
| **E** | Поворот (3 оси) | ✓ | — |
| **R** | Масштаб (по осям) | ✓ | — |

- Тащи стрелки/кольца/кубики гизмо — трансформ применяется сразу.
- **Снап к сетке** — чекбокс в панели: перемещение защёлкивается на «шаг» (по умолчанию = клетка
  сетки сцены), поворот — 15°, масштаб — 0.25.
- Здания, спавны и колайдеры — позиционные: у них только перемещение (поворот/масштаб не нужны).

## Инспектор (по типу выделенного)

- **Объект (glTF/примитив):** Позиция, Поворот XYZ° (полный 3-осевой), Масштаб (по осям),
  Шейдер (Lit/Unlit/Phong) и Тинт-цвет (для glTF-моделей), «Дублировать (Ctrl+D)», «Удалить (Del)».
- **Здание:** тип, Позиция, Команда (0 = соло/кооп, 1/2 = стороны PvP), «Удалить». Параметры
  (hp/rate/урон/волны) в редакторе НЕ правятся — они в `config/buildings.cfg` (см. ниже).
- **Точка спавна:** Позиция, Команда, «Удалить».
- **Колайдер:** Центр, Полуразмер (box), «Удалить». Колайдер = физика (стены/пол), в игре невидим.

## Добавление сущностей

Всё добавляется **в текущий фокус камеры** (центр орбиты) и сразу выделяется.

- **Палитра** (кнопки в панели): «Ядро», «Генератор», «Склад», «Спавнер», «Башня»,
  «Точка спавна», «Колайдер».
- **Браузер `.glb`** (список внизу панели): клик по модели — добавить объект-декор с этой моделью.
  Список сканируется из `assets/models/**` при запуске (положил новый `.glb` → перезапусти редактор).

Совет по расстановке: наведи камеру (пан/зум) на нужное место, затем жми кнопку/модель — появится там.

## Свет и камера сцены

- **Свет (dir)** — направление НА источник света; меняется вживую в рендере.
- **Камера сцены** (раскрывающаяся секция) — параметры игровой ¾-камеры: Дистанция, Наклон (pitch),
  lookHeight, FOV, near, far. Кнопка **«Превью (как в игре)»** ставит облётную камеру редактора под
  эти настройки (фокус на ядре/игроке) — увидеть примерный кадр игрока; **«Свободная»** — вернуть
  обычный облёт.

## Undo / Redo

| Хоткей | Действие |
|---|---|
| **Ctrl+Z** | отменить |
| **Ctrl+Y** или **Ctrl+Shift+Z** | повторить |

Плюс кнопки «Отменить/Повторить» и счётчик глубины стеков в панели. Снимок берётся перед каждой
правкой (перетаскивание гизмо, поля инспектора, добавление/удаление/дублирование, смена материала).

## Сохранение

- **Ctrl+S** или кнопка «Сохранить» — записать в загруженный `.scene`
  (`<assetsDir>/<scenePath>`, перезапись).
- Несохранённые правки помечаются `*` в заголовке панели.
- Формат — тот же текстовый `.scene` (человекочитаемый; директивы — см. ARCHITECTURE §5.1).
  Файл сразу подхватывается клиентом/сервером/сборкой уровня.

## Типичный процесс сборки уровня

1. Скачай CC0-паки (KayKit / Quaternius / Kenney — все отдают `.glb`), положи `.glb` в
   `assets/models/` (можно в подпапки).
2. `run-editor.cmd [scenePath]` — открой пустую/базовую сцену.
3. Расставь **колайдеры** (стены/пол — физика) и **декор** из браузера `.glb`; двигай/поворачивай/
   масштабируй гизмо, включи снап для аккуратной сетки.
4. Поставь **Ядро**, **Спавнеры** (источники врагов), при PvP — **Точки спавна** с командами.
5. Настрой **свет** и **камеру сцены** (превью).
6. **Ctrl+S**. Проверь в игре: `run-desktop.cmd 127.0.0.1 ../../app/src/main/assets <scenePath>` или
   выбери сцену в меню.

## Что где хранится

- **Геометрия/декор/колайдеры/свет/камера/спавны** — в `.scene` (редактор пишет их напрямую).
- **Параметры зданий** (hp, rate, урон, размер волны и т.п.) — в `config/buildings.cfg`, НЕ в сцене:
  сцена только РАЗМЕЩАЕТ здание (тип + позиция + команда), параметры по типу приходят из конфига.
  Поэтому редактор их не показывает.
- **Модели** — `.glb` в `assets/models/`; текстура берётся встроенная из glb (KayKit-атлас).

## Ограничения (текущие)

- Поворот: средняя ось (X в порядке YXZ) ограничена ±90° — для наклонов пропсов достаточно; полный
  Y — без ограничений.
- Дублирование и правка материала/шейдера — только для glTF-объектов (у процедурных общий именованный
  материал сцены).
- Кольцевые объекты (`ring`) не редактируются поштучно.
- Мини-карта карты в самом редакторе не рисуется (top-down — в Lobby-брифинге игры).
